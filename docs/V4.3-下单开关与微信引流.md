## 一、在线下单开关(本期开发)

### 行为定义
后台「交易 → 商店设置 → 在线下单」开关(默认**开启**):

| 位置 | 开启时 | 关闭时 |
|---|---|---|
| 页头购物车入口(PC+H5 菜单) | 显示 | **隐藏** |
| 商品详情「加入购物车」 | 显示 | **隐藏**,价格旁显示「询价」引导 |
| 商品价格展示 | 显示 | **保持显示**(商品浏览不受限) |
| 商品列表/栏目页 | 正常 | 正常(仅询盘商品本就无加购) |
| /cart、/checkout 页 | 正常 | **服务端直出提示页**(SSR 即生效,非 JS 兜底) |
| POST /api/order 下单接口 | 正常 | **403 拒绝**(防绕过前端直调) |
| 询盘表单 | 正常 | 正常 |
| 个人中心「我的订单」 | 正常 | **保留**(历史订单查询属既有权益,非下单入口) |

### 实现要点
- 配置:Setting(group=shop) 键 `orderingEnabled`;缺省/脏值一律按**开启**(存量站点升级零变化);**零迁移**
- 服务层:`getShopConfig().orderingEnabled`(server/shop)
- 下发:前台 layout → SiteHeader prop;(site)/layout 与商品详情页各自读取
- 服务端壳:cart/checkout 拆为「page.tsx 服务端判断 + xxx-client.tsx 客户端交互」
- 公开标志:GET /api/flags 增加 `orderingEnabled`(轻量探活可见)
- 测试:开关语义(缺省 true/显式 false/脏值兜底)+下单接口 403 拒绝(2 例回归锁)

## 二、微信公众号菜单挂域名(零开发,操作指引)

**你的账号类型(个人认证订阅号)支持自定义菜单**,直接配置:

1. 登录微信公众平台 → 左侧「自定义菜单」
2. 添加菜单项 → 菜单内容选「**跳转网页**」
3. 页面地址填:`https://aition.art`(建议按语言给两个菜单:「官网」→ 中文站;或英文站 /en)
4. 保存并发布(菜单对关注者即刻生效)

**注意**:
- 跳转网页**不需要**配置 JS 接口安全域名/网页授权域名(那是 JS-SDK 与网页授权用的,你不做那两项)
- 站点已是响应式,微信内置浏览器打开正常(375px 视口已验收)
- 公众号文章/菜单里贴的链接建议用短、稳的地址(如首页或具体栏目页),避免带查询参数的临时链接

## 三、微信分享支持:能力边界(结论不变)

| 诉求 | 结论 | 原因 |
|---|---|---|
| 微信聊天里显示标题+图卡片(分享卡片) | ❌ 不可行 | ① 微信对非 mp.weixin.qq.com 外链一律纯文字链接(平台策略,所有网站相同);② JS-SDK 自定义分享卡片要求**认证服务号**,个人订阅号无此接口权限 |
| 微信内打开站点 | ✅ 正常 | 响应式已就绪 |
| 站内「转发」入口(复制链接) | ✅ 已具备 | 商品/文章详情互动条含转发(复制链接+提示) |
| 其他平台卡片(QQ/微博/Telegram/X 等) | ✅ 正常 | OG 标签全站就绪(V3.1) |
| 后续可选增强:分享海报(Canvas 生成图) | 候选 | 图片在微信内 100% 可见,可替代卡片传播;如需另行立项 |

## 四、验收指引(本地 localhost:3000)

1. 默认(开启):页头见「购物车」;商品详情见「加入购物车」;`/cart` 正常
2. 后台 → 交易 → 商店设置 → 关闭「开放在线下单」→ 保存
3. 刷新前台:页头购物车消失;商品详情价格仍在、「加入购物车」变为「询价」;/cart 与 /checkout 直接显示「未开放在线下单」提示
4. 重新开启 → 一切恢复
