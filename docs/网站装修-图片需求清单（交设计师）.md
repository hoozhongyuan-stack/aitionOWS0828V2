# aition.xin 装修 · 图片与配色需求清单（交设计师）

> 站点：**aition.xin**（2026-09-11 由 aition.art 更换）｜性质：酒行业「品牌咨询 + 数字化系统解决方案」的顾问品牌站（自媒体为主）
> 本期范围：**只做品牌与页面框架的图，不含文章内容**（文章封面只定规范，等有文章再套）
> 站点语言：中文为主（英文页保留首页 + 关于我）

## 一、先定三件事（决定设计师怎么下手）

### 1. 视觉基调：勃艮第酒红（已定）

面向酒品牌 / 酒厂 / 酒经销商的决策者，卖的是专业与信任，不是热闹。**主色取自当下流行的「勃艮第酒红」**——这个颜色本身就是酒的语言（酒液、酒标、橡木桶），与业务天然一致，也避开了通用"科技蓝"的廉价感。

**建议色板（已按无障碍对比度验算，可直接用）**

| 角色 | 色值 | 用在哪里 | 对比度（实测） |
| --- | --- | --- | --- |
| **主色 · 勃艮第酒红** | `#8E1C2E` | 按钮、链接、强调线、图标 | 白字压上去 **8.91:1**（AAA，很稳） |
| 主色加深 | `#6B1220` | 按钮 hover、页脚、大面积色块 | 白字 **12.12:1** |
| **强调 · 香槟金** | `#C6A15B` | **只在深色底上**做细线、徽标、装饰点缀 | 深底上 **7.69:1** ✅；**浅底上仅 2.35:1 → 绝对不能当文字色** |
| 底色 · 暖白（纸感） | `#FDFBF8` | 页面背景（用暖白替代纯白，配酒红更显贵） | — |
| 次层底 · 暖米 | `#F5EDE4` | 卡片、分区底 | — |
| 正文 · 暖墨 | `#241A1A` | 标题与正文（不用纯黑，纯黑配酒红会发脏） | 暖白底 **16.43:1** |
| 次要文字 · 暖灰 | `#8A7373` | 日期、说明文字 | 建议不要浅于 `#7A6666`，否则读不清 |
| 深色区底 | `#15120E` | 首屏/页脚的深色区间 | 暖米字压上去 **14.28:1** |

**忌用（这几个最容易画错）**

- **正红/大红色**（如 `#E60012`）——马上变促销、变电商，档次掉一档；
- **玫红、紫红、荧光红**——廉价感；
- **大面积铺酒红做背景**——闷且压抑，酒红要用"点"的，不要用"面"的；
- **金色文字放在浅色底上**——对比度只有 2.35:1，屏幕上基本看不清（金色只能用 在深色底上，或作为色块/描边）。

**明暗方向建议：浅色为底 + 深色首屏**

站点内容以长文为主（你的行业分析动辄几千字），**正文区用浅色暖白，阅读最舒服**；**首屏和页脚可以用深色酒红影像撑质感**。也就是"浅底为主、深色点睛"，而不是整站深色。整站深色适合品牌形象站，不适合文章站。

**站内落地（后台 5 个色值，我可以直接配，零代码）**

```
主色 primary    #8E1C2E
辅色 secondary  #F5EDE4
背景 background #FDFBF8
文字 foreground #241A1A
次要文字 muted  #8A7373
```

> 如果你更想要"深色墨金"的观感，平台内置的「窖藏」主题本身就带墨黑底 + 金色 + 朱砂红按钮，但它的按钮红是写死的 `#9E2B25`，要精确改成勃艮第 `#8E1C2E` 需要两行 CSS 小改（约半小时）。

### 2. 现有品牌资产（已找回，见 `brand-assets/现有品牌资产/`）

| 资产 | 规格 | 说明 |
| --- | --- | --- |
| 现有 LOGO | 400×120 PNG 透明底 | 黑金蜘蛛图形 + 「AITION」**深蓝**字标（O 为琥珀金）+ 副标 INSIGHT INTO GROWTH |
| 现有 favicon | 256×256 ICO | 可参考，需 512×512 新版 |
| 联系微信二维码 | 1254×1254 PNG | 尺寸过大，需重出 |
| 公众号二维码 | 258×258 JPG | **偏小，108px 显示下会发虚，需重出** |

**⚠️ 现有 LOGO 有两处必须改**

1. **配色冲突**：字标是**深海军蓝**，与酒红主色放一起会"打架"（一冷一暖）。建议把字标改为**暖墨 `#241A1A` 或勃艮第 `#8E1C2E`**，保留金色做点缀——形成"酒红 + 香槟金"的酒标语言。
2. **需要多版本**：现在这个文件是给浅色底用的。站点首屏是深色影像区、页脚也可能用深色 → **必须补反白版**。

**蜘蛛图形本身有辨识度，建议保留**（重绘为矢量即可），不必从零重做品牌。

### 3. 图片进站的两条通道（决定交付物的形态）

- **通道 A｜后台配置位（固定尺寸，一图一位）**：LOGO、favicon、页脚二维码、首页 Banner、文章封面 —— 这些在后台有明确的上传入口，尺寸必须按标准交。
- **通道 B｜正文插图（随内容走）**：关于我形象照、服务配图、案例图、图表 —— 这些放在文章正文里，没有固定尺寸约束。**建议交付「模板 + 素材包」（统一的配色、边框、字型规范），而不是一次性单图**，否则以后每篇都要重新设计一次。

## 三、逐个说明：目的 + 画面建议

### 1. 页头 LOGO —— 全站品牌门面

**目的**：访客 3 秒内判断"这是谁、做什么的"，是 B 端信任的第一触点。

**平台约束（重要）**：同一个 LOGO 文件同时用在两处 ——
- 页头：当前设定高度 **48px**，宽度自适应（页面左右还有导航和按钮，**页头横向空间有限**）；
- 页脚：高度 **28px**，旁边紧跟站点名文字。

→ 所以 **LOGO 必须做到缩到 28px 高仍然认得出**：图形要简洁，副标文字（INSIGHT INTO GROWTH）在小尺寸下必然糊，建议**副标另出一个精简版**或在小尺寸版本里直接省略副标。

**建议交付**：
- 主版：横版 LOGO，600×180px（3 倍图，对应 200px 显示宽），透明底，**字标用暖墨或勃艮第，金色只做点缀**；
- 精简版：只有图形 + 主字标（不含副标），用于页脚；
- 反白版：深色底上用的白/暖米字标版（首屏、深色页脚）；
- 单色版：纯白或纯墨的单色稿，用于 favicon、印刷、图标场景；
- 有条件给 SVG（矢量，任何尺寸都清晰）。
- **顺带定一件事**：LOGO 里是否要出现中文名（如「爱神」/「爱神AiTion」）？面向国内酒企客户，纯英文 AITION 的识别成本偏高，建议中英组合或中文为主。

### 2. favicon —— 浏览器标签页图标

**目的**：多标签页时的辨识度，也是"这个站靠不靠谱"的细节。

**建议交付**：512×512 PNG（后台上传用），另附含 16/32/48 三档的 .ico。**必须在 16×16 下还能看出形状** → 建议用蜘蛛图形做简化版，**用勃艮第酒红或金色**（这两个色在浏览器浅色/深色标签条上都成立），不要带任何文字。

### 3. 首页首屏 Banner —— 本期最重要的一张图

**目的**：全屏首屏，是站点给人的第一印象。上面会**叠白色大标题 + 副标题 + 两个按钮**（文案由后台配置，设计师不必画字）。

**平台约束（务必遵守）**：
- 图片作为**整屏背景**铺满，模式是"裁剪填充"（object-cover），上面自动加一层**黑色 35% 蒙层**；
- 三种首页布局都拿它当背景，推荐的「全幅聚焦」是**撑满一屏**（桌面约 1440×800，手机约 390×780）；
- **桌面端**：画面中上部要留出白字可读的区域；
- **手机端**：竖屏裁剪很重 —— 「全幅聚焦」布局**只显示画面水平中间约 28% 的竖条**（其他布局约 50%）→ **关键元素必须放在画面水平正中间，两侧视作会被裁掉**。

**建议交付**：3 张 **2560×1440（16:9）** 横版图，作为轮播（5 秒自动切换），色调统一。

**画面建议（酒红方向）**：
- **整体压暗、留白充足**，画面里可以有一处酒红/暖光作为视觉重心（与主色呼应），但**不要整张铺满荧光红**；
- 内容方向：窖池、酒库、橡木桶、瓶身特写、终端货架、数据质感画面；**不要出现具体品牌的商标酒瓶**；
- **避免冷蓝、冷灰、高饱和杂色**——会和暖调酒红主色冲突；黑白照片 + 单点酒红也是很好的处理；
- 三张要像同一个系列（同色调、同构图逻辑），不是三张拼凑；
- 主体居中，四周 15–20% 当作安全裁切区。

### 4. 页脚二维码 —— 微信入口

**目的**：把访客转成微信好友/关注，这是自媒体站最重要的转化动作。

**平台约束**：页脚常驻展示，显示尺寸 **108×108**。

**建议交付**：600×600 正方形 PNG，**四周保留足够留白（≥4 个模块宽度）**，不要加边框、滤镜或渐变叠图，保证扫描识别率。两个二维码风格统一，建议配一条小字引导（如"扫码聊聊你的项目"）。**二维码本身不要染成酒红色**——用标准黑白，识别率优先。

### 5. 社交分享卡片图（OG image）—— 建议本期一并做

**目的**：文章/页面被分享到微信、飞书、LinkedIn 时的缩略图。目前的兜底逻辑是**拿 LOGO 当分享图**，效果很难看。

**平台现状**：系统**没有独立的分享图配置位**，只有"页面 SEO 图 → 品牌 LOGO"的兜底链。要做到每篇文章自动带分享图，需要一次小开发。本期建议先交一张**通用分享图**（酒红底 + 金色 LOGO + 一句话定位），我可以顺手把兜底改成用它。

**建议交付**：1200×630（1.91:1），保证在微信小卡片里裁切后主信息仍在（重要内容放中间 80% 区域）。这是**唯一建议直接铺大色块**的地方——深酒红底 + 金字/白字，在这种小尺寸场景里辨识度最高。

### 6. 顾问形象照（关于我）—— B 端转化利器

**目的**：酒行业咨询是"认人"的生意，"关于我"页有一张可信的形象照，转化率通常明显高于纯文字。

**建议交付**：
- 竖版 **1600×2000（4:5）** 1–2 张（工作场景或半身职业照，背景干净、光线自然，避免过度修图）；
- 方版 1:1（1000×1000）一张，供头像类位置使用；
- 服装避开正红与亮红（会和主色打架），深色/大地色系最稳；
- 拍工作场景（与酒厂/客户交流、看数据、看货架），比正装摆拍更有说服力。

### 7. 服务三卡配图

**目的**：「解决方案」页三档服务（品牌咨询 / 数字化系统落地 / 年度顾问）各一张配图，帮访客快速区分。

**建议交付**：3 张 **1600×1200（4:3）**，同一构图逻辑、同一色调（暖调 + 单点酒红），只换主体元素。**不要用图库风的商务握手照**。

### 8. 文章封面（本期只出模板）

**目的**：首页"最新洞察"卡片与栏目列表的缩略图。

**平台约束**：同一个封面图会在三种裁切下出现 ——
- 卡片 **16:9**（常规）/ **2:1**（首页精选位，裁得更扁）；
- 列表缩略图 **96×64（3:2）**，非常小。

→ **建议交付**：一个 **1600×900 的封面模板**（酒红或暖白底 + 标题文字位 + 统一角标 + 金色分隔线），以后每篇文章套模板出图即可；主体元素放在**画面正中间**，保证 2:1 和 3:2 裁切都不丢信息。

### 9. 正文插图 / 图表规范（本期只出模板）

**目的**：文章正文里的配图、数据图表统一观感。正文栏宽度是 **768px**（会按屏幕缩放），所以图片宽 **1600px 起**就够清晰。

**建议交付**：一套图表样式（配色就用上面的色板：酒红作数据主色、香槟金作对比色、暖灰作网格线；字体、图注样式规则）。**你的内容偏数据论证（文末带"数据来源与口径说明"），图表会大量出现，这套规范比单图更有价值。**

## 四、全局交付规范

| 项目 | 要求 |
| --- | --- |
| 格式 | JPG（照片/Banner）、PNG（LOGO/透明/二维码）、SVG（LOGO 矢量） |
| 体积 | **单张 ≤10MB**（平台硬限制）；Banner 建议压到 1MB 内，兼顾加载速度 |
| 分辨率 | 一律按**2 倍图**交付（表中尺寸已是 2–3 倍口径） |
| 色彩 | sRGB，不要 CMYK；**暗部不要"死黑"**（酒红主色下死黑会糊成一块） |
| 命名 | `位置-版本-尺寸-主题`，例：`logo-横版-浅底-600x180.png`、`banner-01-2560x1440.jpg` |
| 交付 | 按目录交付：`logo/`、`favicon/`、`banner/`、`qrcode/`、`share/`、`photos/`、`templates/`，并附一页"用途对应表" |

## 五、本期不需要做的（别浪费工时）

- **商品图**：商城入口不再露出（代码与数据保留），不需要商品主图/详情图。
- **Banner 以外的装饰插画**：首页其余区块（最新洞察、服务卡、CTA）都用版式与文字承载，不依赖插画。
- **404 / 维护页插画**：现有实现是纯样式（图标 + 文案），无需配图。
- **多语言两套图**：英文页复用同一套图。
- **不要为"酒红"单独做一整套深色稿**：本期推荐浅色为主，深色只出现在首屏影像里。

## 七、给设计师的一句话总结

> 这是一个面向酒行业的顾问品牌站，视觉基调是**勃艮第酒红 `#8E1C2E` + 香槟金 `#C6A15B`**（金色只能用在深底上）、页面以**暖白 `#FDFBF8`** 打底；三个关键位是**首屏 Banner、页头 LOGO、二维码**；LOGO 要能缩到 28px 还认得出、要出浅底/反白/单色三版，**现有深蓝字标必须改色**；Banner 要在手机竖屏裁掉两侧后仍然成立；**所有图不要带文字**（文案由后台配置），避免冷色、避免图库风商务照与具体品牌商标。
