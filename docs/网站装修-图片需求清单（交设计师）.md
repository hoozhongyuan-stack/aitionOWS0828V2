# aition.art 装修 · 图片需求清单（交设计师）

> 站点：**aition.art**｜性质：酒行业「品牌咨询 + 数字化系统解决方案」的顾问品牌站（自媒体为主）
> 本期范围：**只做品牌与页面框架的图，不含文章内容**（文章封面只定规范，等有文章再套）
> 站点语言：中文为主（英文页保留首页 + 关于我）

---

## 一、先定三件事（决定设计师怎么下手）

**1. 站点气质**
面向酒品牌 / 酒厂 / 酒经销商的决策者，卖的是专业与信任，不是热闹。画面基调建议：**克制、有质感、留白充足**。推荐深色墨金方向（平台内置主题「窖藏」，深色底 + 暖金点缀），或用浅色极简。**这一条必须先拍板**，因为它决定 LOGO 用哪一版（见第 2 条）。

**2. 现有品牌资产（已找回，见 `brand-assets/现有品牌资产/`）**

| 资产 | 规格 | 说明 |
| --- | --- | --- |
| 现有 LOGO | 400×120 PNG 透明底 | 黑金蜘蛛图形 + 「AITION」深蓝字标（O 为琥珀金）+ 副标 INSIGHT INTO GROWTH |
| 现有 favicon | 256×256 ICO | 可用于参考，但需要 512×512 新版 |
| 联系微信二维码 | 1254×1254 PNG | 尺寸过大，需重出 |
| 公众号二维码 | 258×258 JPG | **尺寸偏小，108px 显示下会发虚，需重出** |

**关键提醒**：现有 LOGO 是**为浅色底设计的深色字标**。若站点走深色主题，深蓝字标在深底上几乎看不见 → **必须补一版反白/浅色 LOGO**。若保持浅色主题，现有 LOGO 可直接沿用（仍建议重做，现有 400px 宽在高分屏页头略紧）。

**3. 图片进站的两条通道（这决定交付物的形态）**

- **通道 A｜后台配置位（固定尺寸，一图一位）**：LOGO、favicon、页脚二维码、首页 Banner、文章封面 —— 这些在后台有明确的上传入口，尺寸必须按标准交。
- **通道 B｜正文插图（随内容走）**：关于我形象照、服务配图、案例图、图表 —— 这些是放在文章正文里的，没有固定尺寸约束。**建议让设计师交付「模板 + 素材包」（统一的配色、边框、字型规范），而不是一次性单图**，否则以后每篇都要重新设计一次。

## 三、逐个说明：目的 + 画面建议

### 1. 页头 LOGO —— 全站品牌门面

**目的**：访客 3 秒内判断"这是谁、做什么的"，是 B 端信任的第一触点。

**平台约束（重要）**：同一个 LOGO 文件同时用在两处 ——
- 页头：当前设定高度 **48px**，宽度自适应（页面左右还有导航和按钮，**页头横向空间有限**）；
- 页脚：高度 **28px**，旁边紧跟站点名文字。

→ 所以 **LOGO 必须做到缩到 28px 高仍然认得出**：图形要简洁、副标文字（INSIGHT INTO GROWTH）在小尺寸下必然糊，建议**副标另出一个精简版**，或在小尺寸版本里直接省略副标。

**建议交付**：
- 主版：横版 LOGO，宽 600px（3 倍图，对应 200px 显示宽）× 高 180px，透明底；
- 精简版：只有图形 + 主字标（不含副标），用于页脚；
- 深浅两版（浅底用深色字标、深底用反白字标）；
- 有条件的话给 SVG（矢量，任何尺寸都清晰）。
- **顺带定一件事**：LOGO 里是否要出现中文名（如「爱神」/「爱神AiTion」）？面向国内酒企客户，纯英文 AITION 的识别成本偏高，建议中英组合或中文为主。

### 2. favicon —— 浏览器标签页图标

**目的**：多标签页时的辨识度，也是"这个站靠不靠谱"的细节。

**建议交付**：512×512 PNG（平台后台上传用），另附一个含 16/32/48 三档的 .ico。**必须在 16×16 下还能看出形状** → 建议直接用 LOGO 中的**蜘蛛图形**做简化版，不要带任何文字。

### 3. 首页首屏 Banner —— 本期最重要的一张图

**目的**：全屏首屏，是站点给人的第一印象。上面会**叠白色大标题 + 副标题 + 两个按钮**（文案由后台配置，设计师不必画字）。

**平台约束（务必遵守）**：
- 图片作为**整屏背景**铺满，模式是"裁剪填充"（object-cover），上面有一层自动加的**黑色 35% 蒙层**（深色主题下会换成暖墨渐变）；
- 三种首页布局都拿它当背景，其中推荐的「全幅聚焦」是**撑满一屏**（桌面约 1440×800，手机约 390×780）；
- **桌面端**：画面中部要留出白字可读的区域（建议中上部留空）；
- **手机端**：竖屏下裁剪很重 —— 「全幅聚焦」布局**只显示画面水平中间约 28% 的竖条**（其他布局约 50%）→ **关键元素必须放在画面水平正中间，两侧视作会被裁掉**。

**建议交付**：3 张 **2560×1440（16:9）** 横版图，色调统一（作为轮播，5 秒自动切换一张）。
参考：你们现在线上的 3 张 Banner 就是 2560×1440，尺寸标准是对的，需要的是**换掉"卖系统"的旧画面**。

**画面建议**：
- 走深色/暗调，或画面本身有暗部区域，才能承载白色标题；避免大面积高亮白或花哨背景；
- 内容方向：酒行业场景（窖池、酒库、橡木桶、瓶身特写、终端陈列、数据/系统质感画面），**不要出现具体品牌商标的酒瓶**；
- 三张统一视觉语言（同色调、同构图逻辑），像一个系列而不是三张拼凑；
- 主体在中间，四周 15–20% 当作安全裁切区，不要放重要元素。

### 4. 页脚二维码 —— 微信入口

**目的**：把访客转成微信好友/关注，这是自媒体站最重要的转化动作。

**平台约束**：页脚常驻展示，显示尺寸 **108×108**。

**建议交付**：600×600 正方形 PNG（够 2–3 倍清晰），**二维码四周保留足够留白（≥4 个模块宽度）**，不要加边框、滤镜或渐变叠图，保证扫描识别率。两个二维码（个人微信 / 公众号）风格统一，建议配一条小字引导（如"扫码聊聊你的项目"）。

### 5. 社交分享卡片图（OG image）—— 建议本期一并做

**目的**：文章/页面被分享到微信、飞书、LinkedIn 时的缩略图。目前的兜底逻辑是**拿 LOGO 当分享图**，效果很难看。

**平台现状**：系统**没有独立的分享图配置位**，只有"页面 SEO 图 → 品牌 LOGO"的兜底链。要做到每篇文章自动带分享图，需要一次小开发。本期建议先交一张**通用分享图**（含 LOGO + 一句话定位 + 品牌色），我可以顺手把兜底改成用它。

**建议交付**：1200×630（1.91:1），保证在微信小卡片里裁切后仍能看清主信息（重要内容放中间 80% 区域）。

### 6. 顾问形象照（关于我）—— B 端转化利器

**目的**：酒行业咨询是"认人"的生意，"关于我"页有一张可信的形象照，转化率通常明显高于纯文字。

**建议交付**：
- 竖版 **1600×2000（4:5）** 1–2 张（工作场景或半身职业照，背景干净、光线自然，避免过度修图）；
- 方版 1:1（1000×1000）一张，供头像类位置使用；
- 如果拍工作场景（与酒厂/客户交流、看数据看货架），比正装摆拍更有说服力。

### 7. 服务三卡配图

**目的**：「解决方案」页三档服务（品牌咨询 / 数字化系统落地 / 年度顾问）各一张配图，帮访客快速区分。

**建议交付**：3 张 **1600×1200（4:3）**，同一构图逻辑、同一色调，只换主体元素（如：品牌咨询=定位/策略意象，数字化=系统/数据质感，顾问=陪跑/复盘场景）。**不要用图库风的商务握手照**。

### 8. 文章封面（本期只出模板）

**目的**：首页"最新洞察"卡片与栏目列表的缩略图。

**平台约束**：同一个封面图会在三种裁切下出现 ——
- 卡片 **16:9**（常规）/ **2:1**（首页精选位，裁得更扁）；
- 列表缩略图 **96×64（3:2）**，非常小。

→ **建议交付**：一个 **1600×900 的封面模板**（品牌色底 + 标题文字位 + 统一角标），以后每篇文章套模板出图即可；主体元素放在**画面正中间**，保证 2:1 和 3:2 裁切都不丢信息。

### 9. 正文插图 / 图表规范（本期只出模板）

**目的**：文章正文里的配图、数据图表统一观感。正文栏宽度是 **768px**（会按屏幕缩放），所以图片宽 **1600px 起**就够清晰。

**建议交付**：一套图表样式（配色、字体、网格线、强调色规则）+ 图片边框/圆角/图注样式规范。**你的内容偏数据论证（文末还有"数据来源与口径说明"），图表会大量出现，这套规范比单图更有价值。**

## 四、全局交付规范

| 项目 | 要求 |
| --- | --- |
| 格式 | JPG（照片/Banner）、PNG（LOGO/带透明/二维码）、SVG（LOGO 矢量） |
| 体积 | **单张 ≤10MB**（平台硬限制）；Banner 建议压到 1MB 内，兼顾加载速度 |
| 分辨率 | 一律按**2 倍图**交付（表中尺寸已是 2–3 倍口径） |
| 色彩 | sRGB，不要 CMYK；深色主题注意暗部不要"死黑"（会糊成一块） |
| 命名 | `位置-版本-尺寸-主题`，例：`logo-横版-深底-600x180.png`、`banner-01-2560x1440.jpg` |
| 交付 | 建议按目录交付：`logo/`、`favicon/`、`banner/`、`qrcode/`、`share/`、`photos/`、`templates/`，并附一页"用途对应表" |

## 五、本期不需要做的（别浪费工时）

- **商品图**：站点的商城入口不再露出（代码与数据保留），不需要做商品主图/详情图。
- **Banner 以外的装饰插画**：首页其余区块（最新洞察、服务卡、CTA）都用版式与文字承载，不依赖插画。
- **404 / 维护页插画**：现有实现是纯样式（图标 + 文案），无需配图。
- **多语言两套图**：英文页复用同一套图，不需要单独出。

## 六、需要开发配合的一项

**OG 分享图（第 5 项）目前没有后台配置位**，系统只有"页面 SEO 图 → 品牌 LOGO"的兜底。设计师交图之后，需要一次小开发把站点默认分享图指向它（约半小时）。如果本期不做，分享出去就是 LOGO 缩略图，不致命但不专业。

---

## 七、给设计师的一句话总结

> 这是一个面向酒行业的顾问品牌站，**第一屏的 Banner、页头 LOGO、二维码**是三个决定观感与转化的关键位；LOGO 要能缩到 28px 还认得出、Banner 要在手机竖屏裁掉两侧后仍然成立；**所有图不要带文字**（文案由后台配置），风格统一、暗调、留白充足，避免图库风商务照与具体品牌商标。
