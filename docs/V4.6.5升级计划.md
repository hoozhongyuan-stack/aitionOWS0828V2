# AitionOWS V4.6.5 计划(后台交互修补批 · 待审核)

> 分支 main(基于 v4.6.4) · 零迁移 · 预计 1.5~2 天
> 来源:用户验收反馈(文件分组/长标题/下拉菜单)+ 同类问题排查

## 一、问题确认(均经代码与数据核实)

### A 文件管理:切换分组右侧不变 + 数量不对(+ 搜索也无效)
- **根因 1(分组与搜索失效)**:页面把 `folderId`、`keyword` 传给 `/api/admin/media`,但该接口**非 picker 分支只解析 page/mime**(`listMedia({page, mime})`)——两个参数被静默忽略,右侧永远显示全部文件
  - 来源:V4.6.2 重写文件管理时,**只给素材选择器分支(picker=1)加了 folderId 支持**,普通列表分支漏了(`server/media/index.ts` 的 `listMedia` 无 folderId/keyword 形参)
- **根因 2(数量错误)**:左侧计数用的是 `f.children.length + 1` **占位式算法**(与文件数无关);「未分类」徽标显示的也是「当前查询 total」,不是未分类的文件数
- **同类检查**:素材选择器(picker)分支支持 folderId ✓ 但同样不支持 keyword

### B 长标题变形(定制发布弹窗)
- **根因**:`<DialogDescription className="truncate">` —— `truncate` 需要**受限宽度**(overflow hidden + nowrap),而 Radix 的 DialogHeader 无宽度约束,CJK 长标题直接撑破弹窗边界(截图可见文字穿出弹窗)
- **同类排查**:全后台 5 处 DialogDescription(内容定制发布/子账号编辑/用户资料/media-picker/dialogs 通用弹窗),需逐个确认长文本风险
- 另:表格内标题用 `truncate` + 单元格宽度(截图显示省略号正常)属健康;弹窗内长文本是主要风险点

### C 下拉菜单(原生 select,全后台 8 处)
- 现状清点:**8 处原生 `<select>`**——商品栏目筛选、楼层-栏目选择、楼层-样式选择、GEO 引擎筛选、日志动作筛选、富文本字号、富文本颜色、通用弹窗选择器
- **为什么难用**:原生 select 的弹层由**操作系统渲染**——你系统是深色模式,弹层就是黑底白字(与后台浅色 UI 割裂);不支持搜索(引擎列表 18 项要翻)、长列表可能超出屏幕、样式无法统一
- **同类排查结论**:这是全后台一致性问题,一次换干净

### D(上一条提到)收藏后「我的收藏」为空 —— 已排除
- **证据**:拷贝生产库到本地、用真实数据跑读取逻辑 → `listMyFavorites(userId=4)` **正确返回 1 条**(「封坛酒数字化解决方案…」,内容 45 已发布、栏目可见);收藏行、内容行、读逻辑三者均正常
- **结论**:非代码缺陷。你看到空态应为「先打开页面、后点收藏」或浏览器回退缓存导致的陈旧视图
- **建议**:请复现路径「收藏 → **刷新**个人中心」;若刷新后仍空,我加服务端诊断日志排查(该副本已按合规删除)

## 二、修改方案

### A 文件管理(服务层 + API + 页面)
1. `listMedia` 增加 `folderId`(含子文件夹合并,与 picker 口径一致)与 `keyword`(filename contains)形参
2. `/api/admin/media` 非 picker 分支透传 `folderId`/`keyword`
3. 新增**文件夹真实文件数**:`folders` 返回时附带 `count`(一级=自身+子级合计),左侧徽标改用它;「未分类」显示 `folderId IS NULL` 的真实计数
4. 页面:分组切换重置到第 1 页并清空勾选;筛选(类型 Tab)+ 搜索 + 分组三者**可叠加**;空文件夹提示文案区分「分组为空」与「全部为空」
5. 测试:分组过滤/关键字过滤/计数正确性(含子文件夹合并)

### B 长标题与弹窗文本(全后台统一)
1. 定制发布弹窗标题改 `line-clamp-2 break-words`(最多两行、超长自动换行),`DialogContent` 补 `max-w-[calc(100vw-2rem)]` 兜底防溢出
2. 其余 4 处 DialogDescription 逐一检查:动态长文本一律 `break-words`(+ 必要时 line-clamp)
3. 通用弹窗(`dialogs.tsx`)的 title/description 同样加换行约束——一处修复,全后台生效

### C 下拉菜单统一(shadcn Select)
1. 8 处原生 select 全部替换为项目既有 `@/components/ui/select`(与商店设置/发布状态下拉同款):样式统一、宽度可控、长列表自动滚动
2. GEO 引擎下拉(18 项)加**可搜索**能力(受控输入过滤)——否则逐项翻找体验差
3. 富文本字号/颜色**改为工具栏按钮 + 弹层色板/档位面板**(更像编辑器,不再用下拉):字号按钮显示当前档位、颜色按钮显示当前色块
4. 验证:浅色/深色两种系统外观下弹层观感一致(不再跟随 OS)

### D 收藏(不改代码)
- 提供复现与刷新验证结论;若用户复现仍空,再按「服务端诊断日志」路径排查
