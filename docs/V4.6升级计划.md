## 设计定义(与已定稿视觉稿一致)

- **命名**:勃艮第 · Burgundy(preset key = burgundy)——借势 iPhone 18 勃艮第红 + 酒的行业色
- **色彩**:主色勃艮第红 #8E1C2E / 香槟金 #C6A15B(仅深色区块点缀)/ 暖白底 #FDFBF8 / 墨字 #261D18 / 次要暖灰 #8A7B70
- **结构**:浅色为底深色点睛——深色仅 Hero(深酒红渐变)、CTA 横幅、页脚;与窖藏(全暗)气质相反,对齐苹果「干净浅底 + 一个浓郁主色」
- **酒粒子「酒的韵味」**(用户定稿要求):Canvas 双层粒子——金色酒珠气泡(杯中气泡,上升+摇摆+鼠标轻斥)+ 酒香光雾(开瓶香气,慢飘光晕);仅出现在 Hero 与 CTA 横幅深色区块
- **工程克制**:prefers-reduced-motion 不渲染;滚出视口自动暂停;DPR 自适应;浅底内容区零干扰
