# AitionOWS 后台使用手册(交付文档)

> 面向站点运营人员。后台地址:`https://你的域名/zh-CN/admin`
> 所有配置**保存后即时生效**,无需重启、无需找技术人员。

---

## 1. 首次上线五步走

1. **改密码**:首次登录会提示修改默认密码(系统 → 安全)。
2. **配品牌**:站点配置 → 品牌信息:名称、LOGO、ICO、备案号、版权、联系方式。
3. **调主题**:站点配置 → 主题外观:5 个颜色 + 字体字号,保存立即全站生效。
4. **建栏目和导航**:内容管理 → 栏目(如"新闻""产品") → 导航(把栏目挂到页头菜单)。
5. **发内容**:内容管理 → 内容 → 新建,填写标题正文点"保存"即上线。

## 2. 各模块速查

### 概览
- **数据看板**:今日/近 7 天访问量、内容/用户/表单总量、待审核提醒。

### 内容管理
- **内容**:增删改查;状态含草稿/发布/下架/**定时发布**(选定时并填时间,到点自动可见);列表右侧图表按钮可**手动修改或清零**阅读/点赞/转发数。
- **栏目**:树形结构(最多两级),可隐藏、排序、绑定"允许用户投稿";"自定义跳转链接"填了则点击栏目直接外跳。
- **导航**:页头菜单,可关联栏目或任意链接,支持二级菜单、多语言文案、新窗口。
- **文件**:全站上传的图片/视频集中管理;**alt 描述**建议填写(利于搜索引擎理解图片)。

### 获客
- **表单**:新建表单 → 添加字段(文本/单选/多选/下拉/日期/文件)→ 设必填与校验。
  - 关联标识填 `contact` → 表单出现在"联系我们"页;
  - 填某栏目标识(如 `news`)→ 出现在该栏目页底部。
- 数据入口在表单列表的数据库图标:可筛选日期、删除、**导出 CSV**(Excel 直接打开不乱码)。

### 用户与互动
- **互动审核**:评论/投稿默认待审核,**审核通过前台才可见**;敏感词库命中会直接拒绝提交。
- **注册用户**:查看、禁用、启用;禁用立即生效。

### 站点配置
- **主题外观**:主色/辅助色/背景色/文字色/圆角/字体/字号/行高。
- **品牌信息**:含**维护模式**开关——开启后前台全站显示维护提示,后台不受影响。
- **SEO / GEO**:城市/地址/经纬度/服务范围/地域关键词(注入搜索引擎结构化数据);「允许收录」总开关;固定页(首页/联系页等)TDK。
- **语言**:启用语言与默认语言;**界面文案**可覆盖任何内置文字(如首页大标题:命名空间 `site`、键 `heroTitle`);**用户协议**富文本编辑,前台注册页实时同步。
- **功能设置**:
  - 功能开关:点赞/转发/评论/评论需登录/用户投稿/强制登录浏览,均独立开关;
  - 上传限制:类型/大小/数量;
  - 微信登录:填开放平台 AppID/AppSecret 并启用(不启用则前台不显示微信按钮);
  - 错误页:404/500 文案。

### 系统
- **备份**:一键备份数据库/上传文件/完整备份,可下载到本地。
- **安全**:修改管理员密码。

## 3. 内容发布小抄

- 正文编辑器支持:标题、加粗斜体、列表、引用、链接、**本地图片/视频上传**、撤销重做。
- 每篇内容可按语言分别填写(中英文各一个 Tab),某语言留空标题则该语言不展示此内容。
- 每篇内容的「单页 SEO」可独立设置标题/关键词/描述,留空自动用内容标题/摘要。
- 内容 URL 为 `/article/标识`,标识建议用英文短横线(如 `2026-new-product`)。

## 4. 用户投稿流程

1. 功能设置打开「用户投稿」总开关;
2. 在栏目编辑里勾选「允许用户投稿」的栏目;
3. 用户登录后访问 `/zh-CN/submit` 提交图文;
4. 后台「互动审核 → 投稿审核」预览后一键"通过并发布"或"驳回";
5. 用户在"我的投稿"页可见状态。
