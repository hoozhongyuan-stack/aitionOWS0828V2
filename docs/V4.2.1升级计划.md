## 一、功能范围

### 做什么

1. **新增第 4 套主题风格包** `cellar`，中文名「**窖藏**」：深色墨金方向，面向白酒/酒类行业客户（酒厂、酒商、酒类品牌官网）。
2. **新增第 4 套首页布局预设** `spotlight`，中文名「**全幅聚焦**」：全幅首屏 + 超大标题 + 双 CTA，解决"首屏没有气势"的结构性问题（附录 A 诊断的第 3 条）。

4. 后台主题页新增「窖藏」预设卡、后台布局页新增「全幅聚焦」选项，点选即用。

## 二、视觉设计规范（酒主题「窖藏」）

### 2.1 配色（主推「墨金」）

| 配置项 | 值 | 用途 |
|---|---|---|
| `primary` | `#9E2B25` | 朱砂红——按钮、强调色（中式正统感来源） |
| `secondary` | `#26221C` | 墨褐——区块底色 |
| `background` | `#15120E` | 墨黑（带暖调）——页面底色，非纯黑 |
| `foreground` | `#EAE0CF` | 宣纸暖白——正文色 |
| `mutedTextColor` | `#9C8E78` | 暖灰——次要文字 |
| `radius` | `0.125rem` | **近似直角**——中式器物方正感 |
| `fontHeading` | 衬线（后台"衬线 · 杂志感"预设） | 标题典籍感 |

**设计决策说明（供后续维护理解）**：金色**不做 primary**。金色亮度高，金底白字对比度仅约 2.5:1，不达可读性标准，且"满屏金色按钮"廉价。金色只做装饰性点缀（分隔线、描边、hover），这是高端中式设计的通用原则。

### 2.2 主题私有变量（CSS 段内定义，不进调色板）

```css
[data-theme="cellar"] {
  color-scheme: dark;                       /* 深色主题必须：表单控件/滚动条走系统深色 */
  --cellar-gold: #C6A15B;                   /* 金饰：线条、描边、hover */
  --cellar-gold-soft: rgba(198, 161, 91, 0.14);
  --cellar-border: #332C22;                 /* 暖褐边框（比背景亮，深底上可见） */
  --cellar-card: #1C1813;                   /* 卡片底（比页面底略亮一档） */
}
```

### 2.3 排版与形态

- **标题**：衬线 + `letter-spacing: 0.02em`；`h2` 下加 1px 金色短装饰线（对应 harvest 的麦穗装饰位）
- **圆角**：近似直角（`0.125rem`），与禾野 1.1rem、极光 1rem、经典 0.5rem 形成最直观的身份差异
- **卡片**：`--cellar-card` 底 + 1px 暖褐边框；hover 时**金色描边缓慢浮现**——不上浮、不发光（上浮/发光是极光的语言）
- **按钮**：primary 实心（朱砂红 + 白字），hover 微亮；描边按钮用金色系

### 2.4 视觉元素清单（本主题的身份特征）

| 元素 | 做法 | 分寸 |
|---|---|---|
| 金线 | 区块标题下 1px；卡片 hover 描边 | 细、少、准——点睛不铺张 |
| 水墨底 | body 固定层极淡墨晕（`radial-gradient` 模拟，**不引入图片依赖**） | 透明度 0.02～0.03 量级 |
| 印章感 | 小面积朱红标记（"新品/年份"角标底） | **不上真印章图**（易显土） |
| 酒标信息栏 | 小字号 + 大写字母 + 字距 + 金色分隔（用于商品参数区：香型/酒精度/净含量） | 复用现有参数区结构，仅样式覆盖 |
| 图片处理 | 小圆角 + 微画框阴影；hover 缓慢放大 1.03（0.8s ease） | Ken Burns 感，克制 |

### 2.5 动效语言

- 入场：缓慢淡入上移（0.9s），级联延迟 0.1/0.2/0.3s
- 滚动显现：复用现有 `Reveal` 组件，曲线放缓
- 视差：可选启用，系数克制（≤0.2）
- **不做**：光晕漂移、流光、渐变文字——这些是极光的专属语言，避免主题气质混淆
- 降级：`prefers-reduced-motion: reduce` 下呈现终态（照 aurora/harvest 既有结构）

## 三、全幅首屏布局预设 `spotlight` 设计

**解决的问题**：现首页三套预设的首屏都是"左右分栏 + 小图卡片"，标题字号偏小、左侧留白过半、首屏未撑满（下文可见"最新动态"），缺少高端官网的"一眼被镇住"效果。

### 3.1 结构

```
┌─ 全幅 Hero（撑满首屏，扣除页头高度）────────────────────┐
│  背景层：有 Banner 图 → 全幅背景图 + 暗色渐变遮罩        │
│          无 Banner 图 → 各主题的 CSS 视觉层              │
│                        （极光光晕 / 禾野纸纹+光斑 / 窖藏墨晕）│
│  内容层（垂直居中）：                                     │
│    ├ 标签行（可选）：小字 + 字距，如 "GEO · 中英双语 · 企业官网系统" │
│    ├ H1：clamp(2.5rem, 5vw, 4.5rem)，主题字体各自呈现      │
│    ├ 副标题：max-w-2xl                                  │
│    └ 双 CTA：主按钮（预约演示）+ 次按钮（了解产品，描边）   │
│  滚动提示（可选）：底部居中缓慢浮动小箭头                   │
└──────────────────────────────────────────────────────┘
    ↓
[最新动态]  沿用现有 latestGrid（受 sections.latest 开关控制）
    ↓
[首页楼层]  沿用现有 floorBlocks（V3.3 D，零改动）
```

**关键设计取舍**：Hero 背景**不强制依赖素材**——有 Banner 用 Banner，没有则退化为各主题的 CSS 视觉层。这样任何客户（哪怕一张图都没有）启用该预设都不会出现破图或空洞，同时极光/禾野/窖藏各自的主题质感自动生效。

### 3.2 改动点（5 处，**两处白名单必须同时改**）

| # | 文件 | 改动 | 漏改后果 |
|---|---|---|---|
| 1 | `src/server/layout/index.ts:11` | `HomePreset` 类型加 `"spotlight"` | TS 报错（可发现） |
| 2 | `src/server/layout/index.ts:35` | `HOME_PRESETS` Set 加 `"spotlight"` | **静默回退 grid**：保存成功但读出来变回默认，前台看不到效果（最难查，务必同步） |
| 3 | `src/app/api/admin/settings/[group]/route.ts:71` | `layoutSchema` 的 `z.enum(["grid","hero-list","split","list","magazine"])` 加 `"spotlight"` | 保存直接报 `Invalid enum value`（可发现） |
| 4 | `src/app/[locale]/(admin)/admin/(panel)/layout/page.tsx:34` | `HOME_PRESETS` 选项数组加"全幅聚焦"项（含 desc） | 后台选不到 |
| 5 | `src/app/[locale]/(site)/page.tsx` | 新增 `preset === "spotlight"` 渲染分支（现有三支不动） | 前台无效果 |

> **本次调研提示**：布局预设是"双白名单"结构——zod 管**写**（非法值报错），server 层 Set 管**读**（非法值静默回退）。两处不一致时，第 2 处漏改会造成"后台显示已保存、前台却是旧布局"的静默故障，比报错更难定位。这与主题预设的 zod 枚举坑（见四、改动点 3）是同一类"枚举必须多处同步"的问题。

### 3.3 与主题的关系

`spotlight` 与主题正交：四套主题（classic / aurora / harvest / cellar）× 新预设都应正常。背景层用**各主题自己的视觉变量**（极光用 `--aurora-*` 光晕、禾野用纸纹+光斑、窖藏用墨晕），因此不需要为新预设写主题专属 CSS，仅需在 globals.css 补通用布局微调（标题 clamp、首屏高度、滚动提示动画）。

| 首屏撑满导致大屏/小屏比例失衡 | 视觉不适 | 用 `clamp()` + `min-h-svh` 而非固定像素；B8 移动端专项验收 |

**回滚**：改动集中在 8 个文件 + 1 处 CSS 追加，`git revert` 单提交即可；对使用现有主题/布局的站点**零感知**（不切换即完全不生效）。

## 附录 A：官网现状诊断（2026-09-11 实测，用于说明本次首屏改造的动因）

对 aition.art 线上首页做视觉实测（截图存 `gui-test-screenshots/官网现状-harvest主题.png`），"陈旧、不高大上"的四条具体根因：

1. **主题与品牌视觉错配（主因）**：站点当前用「禾野」（暖米白底 + 麦绿按钮 + 衬线标题），而品牌视觉资产是极光系（深藏青夜空 + 光晕）。暖米白在屏幕上呈泛黄纸色，接近旧印刷品观感，是"陈旧感"的直接来源。
2. **冷暖冲突**：全部配图（极光插画、深色后台截图）为冷调深色，贴在暖米白底上色温打架，观感廉价。
3. **首屏没有气势**：左右分栏 + 小图卡片；标题字号偏小；左侧标题下方空出近半屏；首屏未撑满（"最新动态"已露出）。→ 本版 `spotlight` 预设即针对此条。
4. **素材层次不够**：产品截图直贴（无设备外壳/阴影/背景处理）；插画为扁平 SVG 缺质感；首页卡片带日期/阅读/点赞等工具化元信息。

**实测对比**：模拟切换「极光」主题后（`gui-test-screenshots/官网模拟-极光主题.png`），深色底与极光素材完全融合、标题渐变、按钮精致，观感立刻从"农业站"转为"科技产品站"。**但换主题解决不了首屏结构问题**（空白比例、字号层级、未撑满），故本版将两者一并处理。

**后续可选项（P2，不在本版）**：字体体系升级、视觉素材重做（产品截图加 macOS 窗口外壳/玻璃卡片效果）、微交互打磨、首页文章卡片去工具化。
