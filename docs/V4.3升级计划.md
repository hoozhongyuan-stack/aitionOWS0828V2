# AitionOWS V4.3 升级计划与验收记录(第三主题包「禾野 · Harvest」)

> 分支 feat/v41-v42 · 基于 V4.1/V4.2 · 仅本地验收(暂不部署生产)
> 方向已确认:A · 沃野丰收(麦绿+麦穗金+米白,农产品电商/食品转化友好)

## 设计定义

- **命名**:禾野 · Harvest(preset key = harvest)
- **色彩**:主色作物绿 #4A7C43 / 强调丰收金 #D9A441 / 背景暖米白 #FAF7F0 / 文字墨绿 #2C3327 / 次要文字大地棕 #8B6F4E(对比度按 WCAG AA)
- **质感**:暖纸底+极淡编织纹理(CSS 实现,零图片资产)、卡片大圆角暖边框、阳光光斑固定层
- **图形**:区块标题前的麦穗 SVG 装饰(低透明度 data-uri,克制使用)
- **字体**:标题衬线栈('Noto Serif SC' 回退 Songti/Georgia),正文保持无衬线
- **动效**:自然生长系——滚动显现 fade+上移(复用 aurora-reveal 类,harvest 段覆盖为柔和曲线)+装饰微 sway;无霓虹无强视差;prefers-reduced-motion 自动降级

## 实现清单(零迁移,零业务逻辑改动)

1. settings API themeSchema:preset 枚举 + harvest
2. 根 layout:data-theme 挂载判定扩展(aurora|harvest)
3. globals.css:[data-theme="harvest"] 作用域段(基底/纹理/卡片/按钮/标题/hero/装饰/动效;与 aurora 段同模式,classic 零改动)
4. aurora-motion.tsx:启用条件扩展(aurora|harvest;视差 harvest 用柔和系数)
5. 后台主题页:选择卡加「禾野」(含推荐调色板一键填充);header 角色徽章不变

## 验收要点

- 三主题热切换互不影响;classic/aurora 零回归
- harvest 全页面走查:首页/栏目/商品/购物车/结算/个人中心/后台
- 后台调色板在 harvest 下仍可覆盖(主题=结构+默认色,调色板=用户色)
