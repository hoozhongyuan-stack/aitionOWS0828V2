## 0. 结论先行

**站点性质变化**：从「卖 GEO 官网系统的产品站」→「酒行业数字化顾问的个人品牌站 + 内容沉淀池」。
内容的主角不再是产品页，而是**你的行业判断**（如已写的《烟酒店不是被线上打败的，是被线上绕开的》：数据溯源 + 反常识结论 + 给经销商/酒企的判断工具）。

**核心分工**（沿用既定原则）：**平台负责获客，自建站负责沉淀与 AI 可见性**。同一篇内容先发公众号/视频号，再落到本站——本站的价值是"能被 AI 读到并引用"的长期资产，不是流量入口。

**站点骨架一句话**：洞察（专业证明）→ 解决方案（能力说明）→ 案例（信任）→ 咨询（转化）。

## 2. 站点骨架（建议）

### 2.1 一级导航（5 项，去掉产品化的"定价/产品/解决方案矩阵"）

```
首页 | 酒业洞察 | 解决方案 | 案例 | 关于我
```

- 旧导航 20 项（产品 / 产品中心 / 商品演示 / 定价 / GEO 学院 …）**整体废弃**，那是"卖系统"的结构。

### 2.2 栏目（内容承载）

| 栏目 | 定位 | 建议二级 |
| --- | --- | --- |
| **酒业洞察**（主栏目） | 你的判断与行业研究，最高频 | 渠道与终端 / 品牌与消费者 / 数字化实务 |
| **解决方案** | 能力说明与交付边界 | 品牌咨询 / 数字化系统落地 / 年度顾问 |
| **案例复盘** | 脱敏项目复盘 | — |
| **关于我** | 为什么是我做这件事 | — |

### 2.3 首页编排（沿用现有 `spotlight` 全幅聚焦）

1. **首屏**：一句话定位 + 一句可信背书 + 「聊聊你的项目」CTA（双按钮）
2. **最新洞察**：最新 4 篇（楼层 `list` 风格，最新优先）
3. **服务三卡**：品牌咨询 / 数字化系统落地 / 年度顾问
4. **信任位**：实施过的系统类型（扫码营销、一物一码、渠道订货…）+ 案例入口
5. **订阅 / 联系 CTA**

### 2.4 固定页

- **关于我**：酒行业从业经历 + 亲手实施过的系统 + 服务方式（这是 B 端信任的关键，建议写实、写细）
- **联系**：表单（需重建）+ 微信二维码 + 电话
- **订阅**：RSS / 邮件（见 §6 小开发）

## 4. 解决方案页（转化落点，建议三档）

| 服务 | 交付物 | 适合谁 |
| --- | --- | --- |
| 品牌咨询 | 品牌定位与叙事梳理、渠道策略、内容体系 | 品牌模糊、要讲清楚"我是谁"的酒企 |

## 6. 零代码 vs 小开发

**零代码（后台完成，1–2 小时）**
- 新建 4 个栏目（含二级）、重建 5 项导航、重设首页楼层
- 首页 hero 文案换成新定位、页脚地址/联系方式改正
- 重建联系表单并关联到"联系"页
- 主题切 `cellar`「窖藏」（或先保持 classic 对比看效果）

**小开发（可选，按优先级）**

| 项 | 说明 | 工作量 |
| --- | --- | --- |
| A. 隐藏前台购物车入口 | 购物车/登录入口是 `header.tsx` 硬编码（无开关），自媒体站不需要商城 | ~0.5h |
| B. RSS 订阅 | 让公众号/邮件工具/聚合器能订阅，是"自己的触达渠道" | ~0.5d |
| C. 邮件订阅 | 复用 SMTP + 表单能力做订阅名单 | ~1d |
| D. 文章内 CTA 组件 | 文章底部固定"相关服务 + 咨询"区块，提升转化 | ~0.5d |
| E. 案例页模板 | 结构化案例（背景/做法/数据/复盘） | ~1d |

**不建议做**：商城/订单/售后的继续投入（commerce 代码与数据保留，前台不露出即可）。
