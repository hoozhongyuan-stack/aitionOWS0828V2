# AitionOWS V4.2 升级计划与验收记录(商品管理入口/订单售后/媒体文件夹与素材选择器)

> 分支 feat/v41-v42 · 基于 V4.1 · 仅本地验收(暂不部署生产) · 提交 cbaccb8 + 修复若干

## 功能范围(用户确认)

1. **商品管理入口剥离(数据不动)**:后台「交易」新增「商品管理」页(/admin/products)——网格视图(封面/价格/币种/SPU/状态),按商品栏目筛选+搜索+分页(10/50/100);新建/编辑复用内容编辑器。GEO 无影响(数据与 URL 均未变)。
2. **订单售后(仅退款,一单一次)**:买家在「我的订单」对已付款订单(已确认收款/已发货/已完成)申请售后(原因必填)→ 后台订单详情「售后申请」区块审核:通过(退款金额必填≤实付,可改+备注)或拒绝(备注原因)→ 双语结果邮件;通过后订单流转第 6 态 REFUNDED(refundedAt)。退款打款线下执行,系统记录审批结果。
3. **媒体文件夹(二级)+素材选择器**:文件夹新增/重命名/删除(非空禁删;应用层禁第三级);素材选择器弹窗(左侧文件夹树+右侧网格+搜索+上传到当前文件夹);接入 UploadField(封面/图集/LOGO/轮播等)与富文本编辑器(图片/视频「从素材库插入」按钮);上传时可归档文件夹。

## 实现要点

- 迁移:`20260907180000_v42_refund`(OrderRefund 表+Order.refundedAt)、`20260907200000_v42_media_folders`(MediaFolder+MediaAsset.folderId)
- 售后一致性:审核通过在**单事务**内双写(OrderRefund.APPROVED + Order.REFUNDED);金额上限服务端校验
- 权限:商品管理=commerce 组;媒体=content 组(沿 V4.1 体系)
- 演示数据:本地库 demo 商品价格/SPU、测试订单、文件夹「商品图」(生产库无,零影响)
