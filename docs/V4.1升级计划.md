# AitionOWS V4.1 升级计划与验收记录(后台子账号+操作日志+权限隔离)

> 分支 feat/v41-v42 · 基于 4.0.0 · 仅本地验收(暂不部署生产)
> 方案已确认:预定义权限组勾选(非自由细粒度);入口剥离/数据不动的折中属 V4.2。

## 功能范围(用户确认)

1. **子账号**:主账号(OWNER)创建/编辑/禁用/删除/重置密码;独立登录
2. **权限隔离**:预定义权限组——`内容管理`(内容/栏目/导航/轮播图/文件/表单)/`交易管理`(订单)/`互动审核`/`GEO 监测` 四组可勾选;**数据看板、站点配置(主题/布局/品牌/SEO/语言/功能设置/商店设置)、注册用户、子账号、操作日志、备份、安全为主账号专属不可授权**
3. **双层拦截**:侧栏菜单可见性=权限;API 层同步守卫(requireOwner/requirePerm 每次查库,禁用立即生效)
4. **操作日志**:登录成功/失败/登出/改密+全部写操作(内容/栏目/导航/轮播/文件/表单/订单/设置/协议/语言/SEO/用户/子账号/备份/审核),记录操作人/动作/对象/详情/IP;主账号专属查看页,按管理员/动作/日期筛选+分页
