## 一、bug 修复(3 项)

### B1 后台栏目下拉显示英文(反模式残留,17 处)
- **根因**(已实测):内容编辑等页面用 `c.translations[0]?.name` 取名称——依赖**翻译数组顺序**而非站点默认语言。本地实测 6 个栏目中 5 个 `translations[0]` 为 `en`(News/Industrial Equipment…);Prisma 未指定 orderBy,顺序无保证
- **范围**:全后台 17 处(内容编辑 1、互动审核 8、导航 1、其余 7);此前 DEF-013 只修了列表页
- **方案**:把 `adminDisplayName`/`adminTitle` 提为公共 helper(默认语言 zh-CN 优先 → 缺失回退任意语言),替换全部 17 处;**逐处 grep 验证命中**(不再只看脚本 print);新增测试锁「en 在前时仍显示中文」

### B2 数据看板趋势图升级
- **现状问题**:无 hover 提示、无 Y 轴刻度、拖动时文字被选中(`select-none` 缺失)
- **方案**:升级为 **SVG 面积 + 折线趋势图**(自研零依赖):Y 轴刻度与网格线;hover 十字定位 + 数值浮层(日期/PV/UV);图表整体 `select-none`;区间 ≤14 天在数据点常显数值,更长区间靠 hover;移动端横滑
- **补充**:引擎/浏览器兼容性回归(图例、空数据态、单日数据态)

### B3 子账号无法发布内容(权限模型 bug)
- **根因**(已定位):内容编辑页加载语言 Tab 需调 `/api/admin/locales`,该接口守卫为 `requireOwner` → 有 content 权限的子账号也 403「无权限执行此操作」
- **方案**:`/api/admin/locales` **按方法分离守卫**——`GET` 放开给任意已登录管理员(编辑器/投稿必需的非敏感数据),`PUT`(启停语言/改界面文案)**仍严格 requireOwner**
- **同类排查**:复核其他"编辑必需但被锁 OWNER"的读接口(forms/categories 已放行 ✅);子账号发内容全链路实测(新建→保存→发布)

## 二、爬虫与引荐统计扩展(3 项)

### C1 传统搜索引擎独立分区
**口径原则**:AI 可见性与传统搜索抓取**完全隔离**,不合并计数(GEO 指标不被污染)。

- **新增白名单**:`Baiduspider`(百度)、`Sogou web spider` / `Sogou inst spider`(搜狗)、`360Spider` / `HaosouSpider`(360)、`ShenmaSpider`(神马)、`YisouSpider`(一搜)、`Bingbot`(微软,可选)
- **引荐同理**:百度/搜狗/360 引荐归「搜索引擎引荐」,与「AI 渠道引荐」分开
- **数据模型**:`AICrawlStat`/`AICrawlEvent`/`AIReferralStat`/`AIReferralEvent` 各加 `kind` 列(`ai` | `search` | `suspected`,默认 `ai`)+ 索引更新(一次纯增量迁移)
- **界面**:
  - GEO 监测页:分三块并列——「AI 引擎抓取」/「搜索引擎抓取」/「疑似 AI 抓取(推测)」
  - 访问明细页:类型切换扩为四类——AI 爬虫 / 搜索引擎 / 疑似抓取 / AI 引荐
  - CSV 导出:增加 `kind` 列
- **限制说明**:百度文心/新搜索复用 Baiduspider,**无法从 UA 区分"百度AI"与"百度搜索"**——统一按传统搜索统计,界面注明

### C3 「疑似 AI 抓取」启发式统计(用户确认做)
- **定位**:独立只读区块,**明确标注「启发式推测,非确证归因」**,不进正式指标
- **判定规则(可观测信号,同时满足)**:
  1. UA 属通用客户端(`node`/`undici`/`python-requests`/`curl`/`Go-http-client`/`okhttp`/`Java`/`axios` 等)
  2. 无 Cookie(无 `aition_user`/`aition_guest`/`aition_admin`)
  3. 命中 HTML 文档路径(内容详情页 / `llms.txt` / `robots.txt` / 栏目页),排除静态资源与 API
  4. 无 referer 或 referer 非站内
- **诚实标注的限制**(写进界面说明):
  - 无法归因到具体产品(只能说明"有非人类抓取")
  - 会误收 RSS 阅读器/SEO 工具/可用性监控/自建脚本;**提供排除名单**(UA 或 IP 前缀),用户可随时加白
  - 中间件 matcher 不经过静态资源,"同 IP 不取静态资源"这一信号**无法观测**——本版不做该判定
- **噪声控制**:每日采样上限 200 条(超限只累加计数不存明细)
- **展示**:
  - GEO 监测页第三块:次数与时间分布、命中页面 Top 10、**UA 原文样本**、来源 IP 前两段(不展示完整 IP)
  - 访问明细页第四类切换:疑似抓取明细(含 UA 原文便于人工判断)
  - CSV 含 `kind=suspected` 与 UA 列
