# AitionOWS 企业官网模板系统 — 架构设计 / 目录结构 / 数据库 Schema 规划

> 本文档为项目落地前的设计基线,不含业务代码。技术选型已与需求方确认:
> **Next.js 全栈单体 + shadcn/ui + Tailwind + next-intl + SQLite(WAL) + Prisma + Docker Compose。**
> 所有设计以《企业官网模板系统 - Claude Code 专属开发需求说明书》为准,本文档负责把需求翻译为可执行的架构。

## 1. 架构总览

### 1.1 架构形态:Next.js 全栈单体

一个 Next.js(App Router)应用同时承担三件事,内部分层解耦、外部只有一个部署产物:

| 职责 | 承载位置 | 说明 |
|---|---|---|
| 前台官网(SSR) | `app/[locale]/(site)/**` | 服务端渲染,面向 SEO/GEO/AI 抓取 |
| 后台管理 | `app/[locale]/(admin)/admin/**` | 可视化配置,shadcn 表单/表格 |
| 后端接口 | `app/api/**` + `src/server/**` | Route Handlers 薄壳 + 业务服务层 |

**为什么单体**:核心诉求是 SSR + 一键部署 + 极低运维。单体只有一个镜像、一个进程,和"一键部署/重启"天然契合;前后台共享 TS 类型与 Prisma 模型,"配置入库、后台改前台变"落地成本最低。**解耦通过目录分层实现,不靠拆进程。**

### 1.2 请求分层(自上而下)

```
浏览器 / 爬虫
  │
  ▼
middleware.ts        ← 语言协商(next-intl)、维护模式拦截、强制登录、后台鉴权
  │
  ▼
App Router 页面 / Route Handler   ← 只做参数校验(zod)、鉴权、组装,不写业务
  │
  ▼
src/server/**  业务服务层(Service)   ← 全部业务逻辑集中于此,可被页面和 API 复用
  │
  ▼
src/lib/**  基础设施(db / config / storage / i18n / seo / ugc)
  │
  ▼
Prisma  →  SQLite(data/app.db, WAL 模式)
本地文件  →  uploads/**
```

**分层铁律**:页面和 Route Handler **不直接调用 Prisma**,一律经过 `src/server/**` 服务层。这样"单一功能对应独立模块"(需求第 7 条),Claude Code 后续迭代只改对应 service 目录即可。

### 1.3 配置即时生效机制(硬红线核心)

需求硬约束:配置全部入库、**改配置文件/重启无效**、后台改完前台立刻变。实现方式:

```
后台保存配置
  → 写入 Setting 表
  → 调用 revalidateTag('config') / 清空内存缓存
  → 下次 SSR 读取命中新值(无需重启)

SSR 读取配置
  → lib/config/get.ts 先查进程内存缓存(带 tag)
  → 未命中查 DB 并回填缓存
```

- 读多写少,用**内存缓存 + tag 失效**,既保 SSR 性能又保即时生效。
- 主题色、字体、品牌信息、功能开关、SEO 默认值、维护模式等**全部走同一套 `Setting` 读取管线**。

### 1.4 主题注入机制

```
后台调色板/字体配置(存 Setting)
  → 根布局 layout.tsx SSR 读取
  → 注入 CSS 变量到 <html style> 或内联 <style>:root{--primary:...; --font-sans:...}
  → Tailwind 配置里颜色/字体引用这些 CSS 变量
  → shadcn/ui 组件基于同一批变量,全局自动适配
```

关键:**主题变更只改运行时 CSS 变量,不触发重新编译**,契合"无需改代码/无需重启"。

### 1.5 多语言方案(next-intl)

- 路由:`app/[locale]/...`,`middleware.ts` 做语言协商与重定向。
- **静态 UI 文案**:`messages/{locale}.json` 作为内置兜底;后台可在 `UiTranslation` 表覆盖/新增,读取时 DB 优先、文件兜底。
- **内容型数据**(文章、栏目、协议、SEO):用独立 `*Translation` 表按 `locale` 存多语言字段。
- 后台可勾选**默认语言**和**前台启用的语言集合**(存 `Locale` 表 + Setting)。

## 3. 数据库 Schema 规划(Prisma)

> 以下为数据模型设计(非业务代码)。SQLite + Prisma,字段含中文注释。
> 多语言字段策略:内容型实体用独立 `*Translation` 表;配置/统计等非展示文本直接存主表。

### 3.1 枚举定义

```prisma
enum ContentStatus {
  DRAFT       // 草稿
  PUBLISHED   // 已发布
  OFFLINE     // 已下架
  SCHEDULED   // 定时发布(待到点)
  PENDING     // 待审核(用户投稿)
  REJECTED    // 审核驳回
}

enum ContentSource {
  ADMIN       // 后台发布
  UGC         // 用户投稿
}

enum CommentStatus {
  PENDING     // 待审核
  APPROVED    // 已通过
  REJECTED    // 已驳回
}

enum UserStatus {
  ACTIVE      // 正常
  DISABLED    // 禁用
}

enum TargetType {
  CONTENT     // 互动目标:内容(可扩展)
}

enum AgreementType {
  REGISTER    // 用户注册协议
  PRIVACY     // 隐私政策
}
```

### 3.2 配置与站点基础

```prisma
// 通用配置存储:主题色/字体/品牌/GEO默认/功能开关/维护模式/微信凭证/文件限制等全部入库
model Setting {
  id        Int      @id @default(autoincrement())
  group     String   // 分组:theme / brand / seo / features / wechat / upload / i18n ...
  key       String   // 配置键
  value     String   // 值(JSON 字符串,支持任意结构)
  updatedAt DateTime @updatedAt
  @@unique([group, key])
  @@index([group])
}

// 语言配置:后台勾选默认语言与前台启用语言
model Locale {
  code      String  @id      // zh-CN / en ...
  name      String           // 显示名
  isDefault Boolean @default(false)
  enabled   Boolean @default(true)
  sort      Int     @default(0)
}

// 静态 UI 文案覆盖(DB 优先,messages/*.json 兜底)
model UiTranslation {
  id        Int      @id @default(autoincrement())
  locale    String
  namespace String   // 命名空间(如 common / nav / form)
  key       String
  value     String
  @@unique([locale, namespace, key])
  @@index([locale])
}

// 用户协议(注册协议/隐私政策),按语言富文本存储
model Agreement {
  id        Int           @id @default(autoincrement())
  type      AgreementType
  locale    String
  title     String
  body      String        // 富文本 HTML
  updatedAt DateTime      @updatedAt
  @@unique([type, locale])
}
```

### 3.4 CMS:栏目 / 导航 / 内容

```prisma
// 栏目(内容分类,同时是导航来源之一);支持树形、排序、隐藏、自定义模块类型
model Category {
  id           Int                   @id @default(autoincrement())
  slug         String                @unique
  parentId     Int?                  // 父栏目(树形)
  moduleType   String                // 模块类型:news/product/case/article...
  sort         Int                   @default(0)
  visible      Boolean               @default(true)
  externalUrl  String?               // 自定义跳转链接(可选)
  allowSubmit  Boolean               @default(false) // 是否允许用户投稿到本栏目
  createdAt    DateTime              @default(now())
  parent       Category?             @relation("CategoryTree", fields: [parentId], references: [id])
  children     Category[]            @relation("CategoryTree")
  translations CategoryTranslation[]
  contents     Content[]
}

model CategoryTranslation {
  id          Int      @id @default(autoincrement())
  categoryId  Int
  locale      String
  name        String   // 栏目名(多语言)
  description String?
  category    Category @relation(fields: [categoryId], references: [id], onDelete: Cascade)
  @@unique([categoryId, locale])
}

// 导航菜单项(可与栏目关联,也可自定义外链)
model NavItem {
  id          Int      @id @default(autoincrement())
  parentId    Int?
  categoryId  Int?     // 关联栏目(可空)
  label       String   // 兜底文案(多语言走 UiTranslation 或下方 JSON)
  labelI18n   String?  // JSON: { "zh-CN":"...", "en":"..." }
  url         String?  // 自定义链接(与 categoryId 二选一)
  sort        Int      @default(0)
  visible     Boolean  @default(true)
  target      String   @default("_self")
}

// 内容主表:后台发布内容与用户投稿共用(source 区分),含互动统计计数
model Content {
  id           Int                  @id @default(autoincrement())
  slug         String               @unique
  categoryId   Int
  status       ContentStatus        @default(DRAFT)
  source       ContentSource        @default(ADMIN)
  coverMediaId Int?                 // 封面图
  authorUserId Int?                 // UGC 投稿人(前台用户)
  publishAt    DateTime?            // 定时发布时间
  // —— 互动统计计数(后台可手动改/清零)——
  viewCount    Int                  @default(0)
  likeCount    Int                  @default(0)
  shareCount   Int                  @default(0)
  createdAt    DateTime             @default(now())
  updatedAt    DateTime             @updatedAt
  category     Category             @relation(fields: [categoryId], references: [id])
  translations ContentTranslation[]
  comments     Comment[]
  @@index([categoryId, status])
  @@index([status, publishAt])
}

// 内容多语言正文 + 单页独立 TDK
model ContentTranslation {
  id          Int      @id @default(autoincrement())
  contentId   Int
  locale      String
  title       String
  summary     String?
  body        String   // 富文本 HTML(图文/视频/表格/链接/列表)
  // —— 单页 TDK ——
  seoTitle    String?
  seoKeywords String?
  seoDesc     String?
  content     Content  @relation(fields: [contentId], references: [id], onDelete: Cascade)
  @@unique([contentId, locale])
  @@index([locale])
}
```

### 3.5 表单获客

```prisma
// 表单定义:字段结构以 JSON 存(可视化构建器输出),可关联栏目/页面
model Form {
  id           Int              @id @default(autoincrement())
  name         String
  slug         String           @unique
  schema       String           // JSON:字段数组(类型/字段名/必填/提示/校验规则)

  id        Int      @id @default(autoincrement())

  data      String   // JSON:字段名 -> 值
  ip        String?
  userAgent String?
  fingerprint String? // 防重复指纹(ip+表单+关键字段哈希)
  createdAt DateTime @default(now())
  form      Form     @relation(fields: [formId], references: [id], onDelete: Cascade)
  @@index([formId, createdAt])
  @@index([fingerprint])
}
```

### 3.7 UGC:评论 / 点赞 / 转发 / 敏感词

```prisma
// 评论:仅登录用户可评(后台开关),默认待审核,审核通过前台可见
model Comment {
  id        Int           @id @default(autoincrement())
  contentId Int
  userId    Int
  body      String
  status    CommentStatus @default(PENDING)
  ip        String?
  createdAt DateTime      @default(now())
  content   Content       @relation(fields: [contentId], references: [id], onDelete: Cascade)
  user      User          @relation(fields: [userId], references: [id])
  @@index([contentId, status])
  @@index([status])
}

// 点赞记录:用于去重/防刷(登录用 userId,游客用 guestKey 指纹)
model Like {
  id         Int        @id @default(autoincrement())
  targetType TargetType @default(CONTENT)
  targetId   Int
  userId     Int?       // 登录用户
  guestKey   String?    // 游客指纹(ip+ua 哈希 / cookie id)
  createdAt  DateTime   @default(now())
  @@unique([targetType, targetId, userId])
  @@unique([targetType, targetId, guestKey])
  @@index([targetType, targetId])
}

// 转发日志(可选,主要用于统计;计数已冗余在 Content.shareCount)
model ShareLog {
  id         Int        @id @default(autoincrement())
  targetType TargetType @default(CONTENT)
  targetId   Int
  ip         String?
  createdAt  DateTime   @default(now())
  @@index([targetType, targetId])
}

// 敏感词库:评论/投稿基础过滤
model SensitiveWord {
  id      Int      @id @default(autoincrement())
  word    String   @unique
  createdAt DateTime @default(now())
}
// 注:点赞/转发/评论/投稿的"总开关"存 Setting(group='features')
//     用户投稿"允许的类目"由 Category.allowSubmit 控制
```

model DailyStat {

## 5. Docker 部署结构

```
docker-compose.yml
└─ service: app (Next.js standalone)
   ├─ volumes:
   │   ./data     → /app/data      (SQLite: app.db)
   │   ./uploads  → /app/uploads   (本地图片/视频/附件)
   │   ./backups  → /app/backups   (备份输出)
   ├─ env: PORT / AUTH_SECRET / DATABASE_URL=file:./data/app.db / 微信兜底 ...
   └─ (可选) service: caddy → 自动 HTTPS 反代

entrypoint.sh 启动流程(实现"一键部署,自动初始化"):
  1) 确保 data/ uploads/ backups/ 目录存在
  2) npx prisma migrate deploy       # 自动建库建表
  3) 首次运行执行 seed:默认管理员 + 默认配置 + 默认语言 + 敏感词
  4) node server.js                  # 启动 Next.js
```

- 数据库文件 + 上传目录 + 备份全部挂载到宿主机 volume:**重建容器不丢数据**。
- 客户仅需:服务器 + 公网 IP + 域名 →`docker compose up -d`→ 后台配置即上线。
- 备份 = 复制 `data/app.db` + 打包 `uploads/` 到 `backups/`,天然满足"一键备份"。

## 6. 关键工程约束(编码期强制)

1. 页面/Route Handler **不得直接调 Prisma**,一律经 `src/server/**`。
2. 任何展示给用户的配置**不得硬编码**,一律经 `Setting` + `lib/config`(带缓存失效)。
3. 主题/多语言变更**只改运行时数据,不触发重编译/重启**。
4. UGC(评论、投稿)默认状态为待审核,**无任何自动上线分支**。
5. 静态资源只走 `lib/storage` 写本地 `uploads/`,**禁止任何云 SDK**。
6. UI 只用 `components/ui`(shadcn) + Tailwind,**禁止引入其他 UI 库**。
7. 关键函数/配置项**加中文注释**,适配 Claude Code 迭代。

## 7. 技术决策(已定稿)

- **认证库 → 自研轻量 JWT**(不用 Auth.js)。理由:仅"邮箱密码 + 微信"两种,微信非标准 OAuth,Auth.js 无官方 provider、抽象层反成黑盒;自研 `lib/auth`(argon2/bcrypt 哈希 + jose 签发 JWT 到 httpOnly cookie + 微信 OAuth 回调)透明可控、注释友好,契合"杜绝复杂封装"。
- **富文本编辑器 → Tiptap**。headless、输出干净语义化 HTML(服务 SEO)、工具栏用 shadcn 自拼、图片挂本地上传管线。
- **微信登录 → 一期只做 PC 扫码(开放平台网站应用)**;数据库/后台**预留 H5(公众号)第二套 appId/secret 字段**(`Setting(group='wechat')` 加 `h5AppId`/`h5Secret`),逻辑一期不实现,留后路不拖交付。

以上决策已并入本文档架构与脚手架。
