## 主线 E1 · 商品交易化

### 数据模型(一次迁移,纯增量)

```
Content 增加两列:
  priceCents Int?     // 价格(最小货币单位,如"分");null=不展示价格,仅询盘
  currency   String?  // ISO 4217(USD/EUR…);null=用站点默认币种
Setting 新组 shop:
  currency     String  // 站点默认币种(缺省 USD)
  paymentInfo  String  // 线下付款指引(银行账户/PayPal 等,多行文本,后台可编辑)
```

价格存整数「分」避免浮点误差;展示用 `Intl.NumberFormat`(币种+地区格式化)。
**价格留空 = 仅询盘**(商品页不显示购买按钮)——天然支持「可购买 + 可询盘」混合模式。

## 主线 E2 · 交易 MVP(线下付款 + 后台审核)

### 购物车(客户端方案,零新表)

- localStorage 存 `{contentId, qty}` 列表;**结算时服务端按当前价格重算生成快照**(防前端篡改价格)
- 头部导航新增购物车图标(数量角标,实时);极光/经典双主题适配

### 数据模型(与 E1 同一次迁移,纯增量)

```
Order(
  id, no(唯一,如 AO-20260907-XXXX), status,
  userId?(登录用户关联;游客下单为 null), email, name, phone,
  country, address, city, zip, note(买家备注),
  currency, itemsTotalCents, shippingCents, grandTotalCents,
  adminNote?, createdAt, confirmedAt?, shippedAt?, cancelledAt?
)
OrderItem(id, orderId, contentId, titleSnapshot, priceCentsSnapshot, currency, qty)
```

### 订单状态机(5 态,用户已确认增加「已完成」)

```
pending 待确认 → confirmed 已确认收款 → shipped 已发货 → completed 已完成
                    ↓(任意非终态可取消)
                 cancelled 已取消
```

| 状态 | 触发者 | 邮件(买家) |
|---|---|---|
| pending | 买家提交订单 | 下单确认(含订单号 + 线下付款指引 + 金额) |
| confirmed | 后台「确认收款」 | 收款确认(订单进入备货) |
| shipped | 后台「标记发货」(可填物流备注) | 发货通知(含物流备注) |
| completed | 后台「标记完成」 | 无(终态) |
| cancelled | 后台取消(或买家限时未付款后台清理,本版仅手动) | 取消通知 |

管理员在「pending/confirmed」等关键节点同步收到站内通知邮件(复用 `notifyAdmin`)。
邮件模板沿用代码层品牌模板(后台可配 SMTP 通道与商店设置里的付款指引内容;模板文案本身在代码,后台不可编辑——列入不做清单)。

### 页面变化

**前台(3 个新页 + 头部)**:
| 页面 | 内容 |
|---|---|
| `/cart` 购物车页 | 条目列表(图/标题/单价/数量步进/小计/删除)、合计、空车状态、「去结算」 |
| `/checkout` 结算页 | 收货信息表单(email/姓名/电话/国家/地址/城市/邮编/备注;游客可下单,登录用户自动带出资料)+ 订单摘要 + 「提交订单」 |
| `/order/success` 下单结果页 | 订单号、金额、**线下付款指引**(后台商店设置内容)、「我们确认收款后将邮件通知」 |
| 头部导航 | 购物车图标+角标(所有前台页面) |

**订单查询与防篡改**:
- 游客查询:确认邮件含查询链接(email + 订单号参数);结果页只读展示状态
- 下单限频:同邮箱/IP 每小时 5 单
- 服务端校验:商品必须 PUBLISHED、价格按服务端现价重算、数量 1~99

**后台(1 个新组 + 2 个新页)**:
| 页面 | 内容 |
|---|---|
| 侧栏新组「**交易**」→ **订单管理** | 列表:状态页签(全部/待确认/已确认/已发货/已完成/已取消)、订单号/邮箱搜索、分页;行内显示订单号/买家/金额/状态/时间 |
| 订单详情页 | 商品明细(快照标题/单价/数量/小计)、收货信息、买家备注、金额汇总;操作按钮按状态出现:「确认收款」/「标记发货」(填物流备注)/「标记完成」/「取消订单」(填原因);管理员备注;每次操作二次确认 |
