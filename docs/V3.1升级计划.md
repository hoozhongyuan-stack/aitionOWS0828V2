# AitionOWS V3.1 升级计划

> 依据用户确认的三项需求与主题方案整理(2026-08-31)。开发方式:spec-tdd-sdlc(单 run,High-risk——含数据迁移)。

## 需求与方案

### ① 商品规格表英文化(M)
- `ContentTranslation` 新增 `specs`(JSON)列;`Content.specs` 保留为默认/兜底
- 迁移:一次性回填(主表 specs 复制进所有已有翻译);回滚 SQL 随迁移交付
- 读取:详情页优先 translation.specs → 回退 content.specs
- 后台:规格参数编辑器移入语言 Tab(每语言独立维护);PUT 兼容顶层 specs(=默认)
- 数据运营:为生产 7 个演示商品补英文规格表(上线后 API 操作)

### ② 链接分享卡片 OG(S~M)
- 根布局设置 `metadataBase`(NEXT_PUBLIC_SITE_URL),全站 OG 图绝对 URL
- 补齐首页/栏目页/联系页 openGraph(文章/商品已有);兜底图=品牌 LOGO
- 公共助手 buildOpenGraph();auth/协议等工具页维持 noindex 不加 OG

### ③ 看板时间段趋势(S~M)
- `GET /api/admin/dashboard?from=&to=`(校验+≤92 天),返回区间逐日 PV/UV;无参保持近 7 天兼容
- 后台 UI:近 7/30/90 天预设 + 自定义起止日期;图表按区间渲染

## 排期

阶段 1:需求② → 阶段 2:需求③ → 阶段 3:需求①(含迁移,单独验证)→ 统一部署生产。
