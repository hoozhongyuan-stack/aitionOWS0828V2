## A 组 · 功能

### A1 双 LOGO(明暗两版)
- 现状:品牌配置单一 logoUrl,页头(浅底)清晰但页脚(深酒红底)几乎隐形
- 方案:品牌信息页新增「页脚 LOGO(深底用,可选)」上传位;页脚优先用之,未配置回落主 LOGO(存量零变化);需设计师出深底用白色/金色字标
- 工作量 S

### A2 富文本编辑器:文字颜色 + 字号
- 现状:Tiptap 无颜色与字号扩展(已核实)
- 方案:接入 Color 扩展+**预设色板**(品牌酒红/金/墨/白+常用色,不做自由取色);字号**固定档位下拉**(12/14/16/18/20/24/32px,不做自由输入)
- 安全边界(关键):`sanitizeRichHtml` 消毒白名单从"style 属性整体"收紧为**仅定向放行 color/font-size 两个 CSS 属性**的解析,杜绝 style 注入面
- 工作量 M

## B 组 · bug 修复

### B1 前台预览切英文 404
- 根因(已核实):预览链接按当前语言构造;内容无英文翻译行时英文详情查询落空 → 404
- 方案:预览模式(?preview=1)下翻译缺失**回退默认语言内容**;正式访客路径不受影响(仍 404,SEO 语义不变)
- 工作量 S

### B2 定制发布弹窗布局错乱
- 根因:发布时间行日期输入与时/分下拉挤一行,日期框被压缩重叠(V4.3.0 遗留)
- 方案:弹窗内两行网格(日期独占一行,时/分并排一行),窄屏自适应
- 工作量 XS

### B3 发布时间语义(「立即发布」与前台展示)
- 现状(已核实):立即发布不写 publishAt → 列表显示「(立即发布)」;前台展示回退创建时间
- 方案:①立即发布时写入**当时时刻**为 publishAt;②存量已发布且 publishAt 为空的内容一次性回填为各自创建时间(前台展示无变化,隐式变显式);③此后前台展示=发布时间=真实面世时刻;发布后编辑内容不改变发布时间(维持现状语义)
- 工作量 S(含一次轻量数据回填)

## C 组 · 弹窗系统统一(27 处原生弹窗全量升级)

- 现状:全后台 27 处 window.prompt/confirm 原生弹窗(14 个文件),样式不可控、顶部弹出、「输入文件夹 ID」反人类
- 方案:新建 **ConfirmDialog / PromptDialog + useConfirm()/usePrompt()**(Promise 风格,调用形态与现有一致,改造量最小);shadcn Dialog 居中遮罩品牌化,危险操作红色确认语义
- **移动分组交互重设计**:输入 ID → **下拉选择已有文件夹**(按名称显示含二级缩进+「未分类」);单卡「分组」与批量「修改分组」共用;移动成功后自动切换到目标文件夹
- 覆盖清单:文件管理 6 / 素材选择器 3 / 内容·栏目·导航·表单·审核·用户·子账号等删除禁用确认 14 / 订单·备份·商品 4
- 工作量 1 天(基建半天+替换半天)
