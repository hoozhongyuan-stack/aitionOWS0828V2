## 主线 A · GEO 监测二期（引用探测 + 周报）

### A1. 引用探测任务

回答「是否被 AI 引用」：预设问题清单 → 定时向各 AI 引擎发起查询 → 快照回答 → 检测品牌/域名是否出现 → 生成差异报告（首次被引用/掉出）。

**引擎适配器（可插拔，后台配置 API Key，无 Key 引擎跳过）**：
| 适配器 | 接口 | 引用来源 |
|---|---|---|
| Perplexity（官方 API，sonar 系列） | ✅ 回答自带引用来源列表（最佳） | API 付费 |
| OpenAI 兼容适配器 | DeepSeek / Kimi(月之暗面) / 智谱 GLM / 豆包(火山方舟) 等国内外 OpenAI 兼容 API，开启联网搜索参数 | 各平台 API 付费 |
| Gemini API | google 检索 grounding | API 付费 |
| 人工登记模式（无 Key 兜底） | 页面列出预设问题+入口链接，管理员手动查询后登记结果 | 免费 |

### A2. 数据模型（一次迁移，纯增量）
```
GeoProbeQuestion(id, question, engines, enabled, createdAt)        探测问题清单
GeoProbeSnapshot(id, questionId, engine, answerDigest, mentioned   探测快照
                 bool, sourcesJson, probedAt, status)
```
- 快照保留：永久（体量小——每日每问题×引擎 1 行）

### A3. 后台「GEO 监测」页扩展
- 新增「引用探测」Tab：问题清单管理 / 手动立即探测 / 探测历史（按引擎×问题时间线）/ mentioned 变化趋势
- 探测频率：每日 1 次（后台可配）
- 探测引擎:后台勾选启用（有 Key 的才可勾）

### A4. GEO 周报邮件
- 每周一 08:00 自动发送上周摘要（复用 V3.1 邮件模板层）：AI 爬虫趋势 / Top 页面 / AI 渠道引荐 / 引用探测变化
- 发送渠道：沿用 SMTP 配置；无 SMTP 时跳过（沿 NFR-004 静默语义）

### A5. 验收摘要
- 预设问题 → 立即探测 → 快照含 mentioned 判定与来源
- 每日自动探测（cron 或惰性触发）→ 历史可回看
- 周报邮件按配置触发（SMTP 未配置时静默跳过）

工作量：**M**（约 1 周）

## 主线 B · 微信分享：约束与替代方案

**约束说明**：微信 JS-SDK 分享卡片要求**认证服务号**；你当前是**个人认证订阅号**——不具备 JS-SDK 权限（微信接口权限清单硬性规定，无法绕过）。**且微信聊天对普通外链本就不渲染卡片**（V3.2 已分析）——即便升级服务号，聊天发外链仍是纯链接。

### B1. 推荐替代：内容分享海报（Canvas 生成图）
用户点商品/文章详情页「生成分享图」→ 前端 Canvas 绘制精美分享海报（标题+摘要+封面图+站点品牌+小程序样式二维码/链接）→ 长按保存到相册 → 微信聊天发图片（图片在微信 100% 可见，传播效果优于链接）。

- 纯前端实现（Canvas 2D），零后端开发；适配经典/极光双主题
- 工作量：**S～M**（3~4 天，含海报视觉打磨）

### B2. 备选：升级服务号后再立项 JS-SDK
未来若有认证服务号，JS-SDK 分享卡片可按 V3.2 已预留的配置位快速立项。

- 或 B 暂缓（等未来有服务号再议）？
